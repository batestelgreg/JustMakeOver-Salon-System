\# Just Make Over Salon System 💇‍♀️💅



> \*\*Status:\*\* 🚧 On Progress System



An enterprise-grade desktop management application built for beauty salons and spas to streamline internal operations, access controls, inventory, and purchasing workflows.



\---



\## 🚀 Tech Stack



\* \*\*Language \& Framework:\*\* C#, .NET Framework 4.8 (Windows Forms)

\* \*\*UI Architecture:\*\* Microsoft WebView2 (HTML, CSS, JavaScript frontend bridging to C# backend)

\* \*\*Database:\*\* Microsoft SQL Server (T-SQL, Stored Procedures, and Relational Schema)

\## 🛠️ Getting Started



1\. Open the solution file (`JustMakeOverSalonApp.sln`) in \*\*Visual Studio\*\*.

2\. Restore NuGet packages.

3\. Configure your SQL Server connection string in `App.config`.

4\. Build and run the project (`F5`).
